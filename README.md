\# 💧 Calculadora Hídrica — POO / APS



Aplicação desktop desenvolvida em \*\*Java 17\*\* e \*\*JavaFX\*\* com suporte a base de dados \*\*SQLite\*\*, criada para a disciplina de Programação Orientada a Objetos (APS). O sistema permite calcular o consumo mensal de água, analisar faixas de tarifa estaduais e comparar os hábitos de consumo com os indicadores de sustentabilidade da ONU.



\---



\## 🚀 Tecnologias Utilizadas



\* \*\*Linguagem:\*\* Java 17

\* \*\*Interface Gráfica:\*\* JavaFX (FXML)

\* \*\*Gestão de Dependências:\*\* Apache Maven

\* \*\*Base de Dados:\*\* SQLite (`sqlite-jdbc`)



\---



\## 📌 Funcionalidades



\* 📊 \*\*Cálculo de Consumo:\*\* Registo e cálculo de gastos hídricos em m³.

\* 🏢 \*\*Análise Tarifária:\*\* Leitura de coeficientes e faixas tarifárias das concessionárias estaduais.

\* 🌿 \*\*Meta Sustentável:\*\* Comparativo direto com os níveis de consumo recomendado.

\* 💾 \*\*Persistência de Dados:\*\* Armazenamento local via base de dados SQLite (`agua.db`).



\---



\## 🛠️ Como Executar o Projeto



\### Pré-requisitos

\* Java Development Kit (JDK) 17 ou superior

\* Apache Maven
